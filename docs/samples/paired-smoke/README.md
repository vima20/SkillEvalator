# Sample: paired smoke evaluation (no OpenAI)

Generated by `npm run smoke:paired` (known-bad baseline vs known-good candidate).

| File | Contents |
| --- | --- |
| `evaluation.json` | evaluationId + baseline/candidate run ids |
| `comparison.json` | lift, INCONCLUSIVE (dry-run/smoke), parity, per-task deltas |
| `baseline-result.json` | baseline leg `result.json` |
| `candidate-result.json` | candidate leg `result.json` |

This is **D5 plumbing evidence**, not an official OpenAI pilot. For Unikie acceptance pilot, run official baseline↔candidate live and archive `data/results/eval_*` separately.
